# 🏠 House Price Predictor

An interactive Streamlit web application that predicts house sale prices based on six key property features using a trained Scikit-Learn Linear Regression model.

## Features

- **Above-ground living area** (sq ft)
- **Overall quality** (1–10 scale)
- **Total basement area** (sq ft)
- **Garage area** (sq ft)
- **Year built**
- **Number of full bathrooms**

## Local Setup

1. **Clone the repository:**
   ```bash
   git clone <REPO_URL>
   cd house_price_streamlit_app
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit app:**
   ```bash
   streamlit run app.py
   ```
